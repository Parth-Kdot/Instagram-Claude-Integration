A reliable no-setup option that works without an API key — the feed loops through the playlist.
Walkthrough Get a free API key in ~2 minutes
  1. Open the Google Cloud Console and sign in. Pick a project from the top bar, or create one if you don't have any.
  2. Go to APIs & Services → Library. Search YouTube Data API v3, open it, and click Enable.
  3. Open the Credentials tab (left menu: APIs & Services → Credentials).
  4. Click + Create Credentials at the top, then choose API key. Your key is generated instantly.
  5. Recommended: on that key click Edit / Restrict key → under API restrictions select YouTube Data API v3 → Save. (Leave Application restrictions set to None — that's fine for an extension.)
  6. Copy the key (it starts with AIza…) and paste it in the field above. Hit Save. Done.
